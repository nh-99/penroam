## Simulated or proxied (be careful reading results)

* Linux E2E used real XTest input in a **nested Xephyr X server** (software rendering) because
  the desktop session locked; benchmarks also ran on the real Wayland session.
* BOOX plumbing check uses an **injected** stroke (`injectTestStroke`, marked `simulated` in
  the stroke's input metadata) — it does not test Onyx input.
* Pressure, palm, pinch and coalesced-sample handling are covered by unit/engine tests, not by
  real pens in M01.

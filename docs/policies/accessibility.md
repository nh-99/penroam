# Accessibility

Penroam is a handwriting app, so much of it depends on a pen and on seeing the page. This page says
what works today. It is not a claim of conformance with any standard: no accessibility audit has
been done, and no screen reader run has been recorded.

## What the app has

* Light, dark and high-contrast ePaper themes, and it follows the system theme.
* Keyboard shortcuts for each tool, and text can be typed on any page.
* Dialogs, tabs and menus use ARIA roles and labels.
* Pressure sensitivity can be turned off, and fingers, mouse or stylus can all draw.

## What doesn't work yet

* Handwriting on the page isn't exposed to screen readers, so handwritten notes can't be read aloud.
* The canvas has no keyboard equivalent for drawing, selecting or moving ink.

If something stops you from using Penroam, please [tell us](../support.md).

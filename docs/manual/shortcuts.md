# Keyboard shortcuts

[Manual](README.md) › Keyboard shortcuts

On macOS, use `Cmd` wherever this page says `Ctrl`.

## In the library

| Keys | Does |
|---|---|
| `Ctrl+K` or `Ctrl+F` | Search all notebooks |

## In a notebook

| Keys | Does |
|---|---|
| `P` | Pen |
| `M` | Highlighter |
| `E` | Eraser |
| `V` | Select |
| `L` | Lasso |
| `T` | Text |
| `H` | Pan |
| `R` | Show or hide the ruler |
| `[` / `]` | Turn the ruler to the previous / next 15° (while it is shown) |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Ctrl+A` | Select everything on the page |
| `Delete` or `Backspace` | Delete the selection |
| `Enter` | Edit the selected text box |
| `Esc` | Clear the selection, or finish the text box you're editing |
| `Ctrl+=` / `Ctrl+-` | Zoom in / out |
| `Ctrl+0` | Fit the page to the window width |
| `PgDn` / `PgUp` | Next / previous page (also `→` / `←` when nothing is selected) |
| `Ctrl+Shift+N` | Add a page |
| `Ctrl+K` or `Ctrl+F` | Search |
| `Ctrl+S` | Write everything to disk now |
| `Ctrl+P` | Print |
| `Alt` while placing text | Place it without snapping into line |

## While editing text

| Keys | Does |
|---|---|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+K` | Link |
| `Enter` | New line (carries a list on) |
| `Esc` | Finish the text box |

## In a spreadsheet

| Keys | Does |
|---|---|
| Typing | Replace the cell |
| `Enter`, `F2` or double-click | Change what's in the cell |
| `Enter` / `Tab` | Move down / across (`Tab` in the last cell adds a row) |
| Arrow keys | Move around |
| `Shift` + arrows | Select several cells |
| `Esc` | Cancel a change |
| `Delete` | Clear the selected cells |
| `Space` | Tick or untick a checkbox |
| `Ctrl+D` | Fill the top cell down |
| `Ctrl+C` / `Ctrl+V` | Copy / paste blocks of cells |
| `Ctrl+B` / `Ctrl+I` | Bold / italic |
| `Ctrl+Z` | Undo |

## In the guided tour

| Keys | Does |
|---|---|
| `→` / `←` | Next / previous step |
| `Esc` | Close the tour |
